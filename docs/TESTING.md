# Testing

- tests/test_pdfdocument.cpp: plain assert-style checks on PdfDocument
  (load OK, page count, page size, render size, missing-file error).
  Runs via ctest against resources/test.pdf.
- resources/test.pdf is generated by scripts/make-test-pdf.ps1 (original
  content, redistributable) and committed.
- Framework note: plain asserts on purpose; adopt Catch2 only when test
  count makes it worthwhile (docs/DEPENDENCIES.md rule applies).
- Manual smoke: open a real PDF, navigate, zoom, resize window in fit modes.
